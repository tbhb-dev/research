# The `_` namespace

This namespace holds general research for tbhb-dev work that doesn't belong to one project. Each report gets its own directory here, `r-NNNNNN-<slug>/`, with the report in `REPORT.md`. Its ID takes the form `_/R-NNNNNN`, and the namespace numbers its reports from its own six-digit sequence. See [AGENTS.md](../../AGENTS.md).
